# Documentation du Fork GeneWeb

Ce répertoire contient toute la documentation du fork GeneWeb organisée autour de 3 piliers de développement.

## Structure

- **[connaissances-acquises.md](./connaissances-acquises.md)** : Synthèse des connaissances acquises lors de l'exploration initiale du code GeneWeb
- **[pilier-1-champs/](./pilier-1-champs/)** : Documentation sur la modification/ajout/transformation de champs
- **[pilier-2-organisations/](./pilier-2-organisations/)** : Documentation sur la création de l'entité "Organisation"
- **[pilier-3-imports/](./pilier-3-imports/)** : Documentation sur les imports automatisés (Excel/API)

## Vue d'ensemble des 3 Piliers

### Pilier 1 : Modification/ajout/transformation de champs

Amélioration et extension des champs existants dans GeneWeb :
- Transformation du système de sources (multi-sources avec métadonnées)
- Ajout de nouveaux champs aux événements
- Transformation de champs existants

Voir [pilier-1-champs/README.md](./pilier-1-champs/README.md)

### Pilier 2 : Création d'entité "Organisation"

Ajout d'un nouveau type d'entité principale pour représenter les organisations :
- Entreprises, écoles, associations, etc.
- Liens avec les personnes et événements
- CRUD complet pour les organisations

Voir [pilier-2-organisations/README.md](./pilier-2-organisations/README.md)

### Pilier 3 : Imports automatisés

Système d'import automatisé de données :
- Import depuis fichiers Excel
- Import via API
- Validation et transformation des données

Voir [pilier-3-imports/README.md](./pilier-3-imports/README.md)
